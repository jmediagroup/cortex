# Marketing UI Kit

Recreation of the Cortex marketing site (cortex.vip) landing page from `app/page.tsx`. Sticky blurred nav, radial-gradient hero with grid bg, tool-card grid, pricing, manifesto, and dark CTA block.

## Components
- `Nav.jsx` — sticky blurred nav with gradient brain mark
- `Hero.jsx` — headline, gradient text, float blobs, CTA pair, stats bar
- `ToolCard.jsx` — calculator tile with gradient icon chip + Free tag
- `ToolGrid.jsx` — 3-column tool grid
- `PricingCard.jsx` — Free / Pro tiers
- `ManifestoBlock.jsx` — dark indigo CTA container
- `Footer.jsx` — slate-950 footer

## Entry
`index.html` — full landing page.
