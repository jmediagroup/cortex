# Cortex Mobile — UI Kit

Dark "Trust & Growth" finance app recreation. Based on the mobile brief: Pulse dashboard cards, Smart Amount input, Sankey cash flow, Safe-to-Spend Orbit, Predictive ghost charts.

## Components
- `Icons.jsx` — shared lucide-style glyphs
- `Chrome.jsx` — iOS status bar + tab bar + section header
- `PulseCard.jsx` — frosted account card with sparkline and long-press expansion
- `SmartAmount.jsx` — adaptive input that glows emerald for savings, crimson for debt
- `SafeToSpend.jsx` — orbit ring around daily budget
- `Sankey.jsx` — left-to-right cash flow map
- `GhostChart.jsx` — predictive projection line with dotted future
- `TransactionRow.jsx` — list row

## Entry
`index.html` — home screen in an iOS frame with all components composed together.
